  <name>Task 1: Create cluster/32_smoke.slurm template</name>
  <files>cluster/32_smoke.slurm</files>
  <action>
    Create a new SLURM template that fits ONE model under ONE
    parameterization, with output landing under
    `models/bayesian/32_smoke_${KAPPA_MODE}/${MODEL}_*` (per-mode subdir
    keeps the 4 .nc files cleanly separated; no filename mangling needed).

    Required SLURM headers (model after `cluster/04b_bayesian_gpu.slurm`):
      - 4 hours walltime (smoke run, smaller subsample)
      - 1 GPU (ngpus=1) for Bayesian; CPU for qlearning Bayesian (qlearning
        is CPU-fast)
      - Standard logs to `logs/cluster/32_smoke/`

    Required env vars (with defaults):
      - `MODEL` (no default — must be passed)
      - `KAPPA_MODE` (default: softmax)
      - `STAGE` (one of: `bayesian`, `mle`; default: `bayesian`)
      - `OUT_SUBDIR` (default: `32_smoke_${KAPPA_MODE}` - mode-specific subdir)
      - `SUBSAMPLE_N` (default: 30 — small enough to fit in 4h walltime)

    Body:
      ```bash
      KAPPA_MODE="${KAPPA_MODE:-softmax}"
      STAGE="${STAGE:-bayesian}"
      SUBSAMPLE_N="${SUBSAMPLE_N:-30}"

      # Sanity prints
      echo "Phase 32 smoke fit"
      echo "  MODEL:          $MODEL"
      echo "  KAPPA_MODE:     $KAPPA_MODE"
      echo "  STAGE:          $STAGE"
      echo "  SUBSAMPLE_N:    $SUBSAMPLE_N"
      echo "  OUT_SUBDIR:     $OUT_SUBDIR"

      # Subsample data for smoke speed (head N participants)
      SMOKE_DATA="data/processed/task_trials_long_${SUBSAMPLE_N}p_smoke.csv"
      if [ ! -f "$SMOKE_DATA" ]; then
          python -c "
      import pandas as pd
      df = pd.read_csv('data/processed/task_trials_long.csv')
      pids = df['participant_id'].unique()[:${SUBSAMPLE_N}]
      df[df['participant_id'].isin(pids)].to_csv('$SMOKE_DATA', index=False)
      print(f'Wrote $SMOKE_DATA with {len(pids)} participants')
      "
      fi

      # Mode-specific output subdir keeps softmax and convex artifacts separate.
      # OUT_SUBDIR default is "32_smoke_${KAPPA_MODE}" -> e.g. 32_smoke_softmax
      # or 32_smoke_convex. fit_baseline.py / fit_mle.py both expose
      # --output-subdir (verified 2026-05-03 against fit_baseline.py:193).
      OUT_SUBDIR="${OUT_SUBDIR:-32_smoke_${KAPPA_MODE}}"

      if [ "$STAGE" = "bayesian" ]; then
          python scripts/04_model_fitting/b_bayesian/fit_baseline.py \
              --model "$MODEL" \
              --kappa-parameterization "$KAPPA_MODE" \
              --data "$SMOKE_DATA" \
              --output-subdir "$OUT_SUBDIR"
      else
          python scripts/04_model_fitting/a_mle/fit_mle.py \
              --model "$MODEL" \
              --kappa-parameterization "$KAPPA_MODE" \
              --data "$SMOKE_DATA" \
              --output-subdir "$OUT_SUBDIR"
      fi
      ```

    NOTE on `--output-subdir`: Verified to exist in fit_baseline.py
    (line 193). For fit_mle.py, if `--output-subdir` does NOT exist on
    that CLI as of Plan 32-04 completion, add it as part of Task 4
    (small CLI extension - mirror the fit_baseline.py implementation).
    The smoke artifacts MUST land at separate per-mode subdirs to enable
    the convex-vs-softmax regression comparison in Task 3.

    Use POSIX bash, run under `set -e` with EXIT trap for cleanup
    (per feedback_shell_pipeline_patterns.md memory).
  </action>
