<objective>
Implement the Collins 2025 softmax-bias κ parameterization (κ ∈ [−1, 1])
alongside the existing Senta 2025 convex-mixture κ parameterization
(κ ∈ [0, 1]), gated by a single CLI flag `--kappa-parameterization
{softmax,convex}` (default `softmax`) that threads through every layer of
the fitting stack: CLI entries → MLE engine → Bayesian engine →
MODEL_REGISTRY κ bounds → JAX likelihoods (per model) → NumPyro hierarchical
wrappers → run-metadata schema → cluster orchestrator.

Purpose: Research doc Phase D-2 + user decision 2026-05-03 promote D-2 from
"v5.1 candidate" to "v5.0 ship" because the convex-mixture formulation has
boundary pathologies (likelihood gradient → 0 at κ = 0; degenerate at κ = 1)
that plausibly explain why M3's Bayesian fit is multimodal where Collins's
MLE fits converge. Softmax-bias has informative gradient everywhere on the
support and admits negative κ (action-avoidance), which may be meaningful
for trauma-exposed participants.

Output: Dual-mode κ implementation with a documented revert path. ~280 LOC
across ~17 files. v4 closure preserved. Backward-compat tests pass under
both modes. Existing convex-mode artifacts remain bit-reproducible via
`--kappa-parameterization convex`.

    ```python
    def sample_unbounded_normal_param(
        name: str,
        *,
        n_participants: int,
        mu_prior_loc: float = 0.0,
        mu_prior_scale: float = 0.5,
        sigma_prior_scale: float = 0.5,
        clip_lower: float | None = None,
        clip_upper: float | None = None,
    ) -> jnp.ndarray:
        """Sample a non-centered unbounded parameter on the real line.

        Used for softmax-bias κ (Collins 2025) where κ ∈ ℝ (or clipped to
        [−1, 1] for paper conformance). No Phi_approx transform — the
        sampled value is the raw parameter value.

        Implements:
            mu_pr   ~ Normal(mu_prior_loc, mu_prior_scale)
            sigma_pr ~ HalfNormal(sigma_prior_scale)
            z_i    ~ Normal(0, 1)  for i = 1 .. n_participants
            theta_i = mu_pr + sigma_pr * z_i
            (optionally clipped to [clip_lower, clip_upper])

        Parameters
        ----------
        name : str
            Base name for NumPyro sites: ``{name}_mu_pr``, ``{name}_sigma_pr``,
            ``{name}_z``, ``{name}``.
        n_participants : int
            Number of participants.
        mu_prior_loc : float
            Location of the Normal prior on the group mean. Default 0.0.
        mu_prior_scale : float
            Scale of the Normal prior on the group mean. Default 0.5
            (tighter than the bounded helper's default of 1.0 because
            unbounded κ in [-1, 1] needs less group-level wiggle).
        sigma_prior_scale : float
            Scale of HalfNormal on inter-individual SD. Default 0.5.
        clip_lower, clip_upper : float | None
            Optional hard bounds applied via ``jnp.clip``. Use for paper
            conformance to Collins 2025 κ ∈ [−1, 1]. Default None (no clip).

        Returns
        -------
        jnp.ndarray
            Array of shape ``(n_participants,)`` on ℝ (or clipped).
        """
        mu_pr = numpyro.sample(
            f"{name}_mu_pr",
            dist.Normal(mu_prior_loc, mu_prior_scale),
        )
        sigma_pr = numpyro.sample(
            f"{name}_sigma_pr",
            dist.HalfNormal(sigma_prior_scale),
        )
        z = numpyro.sample(
            f"{name}_z",
            dist.Normal(0, 1).expand([n_participants]),
        )
        theta = mu_pr + sigma_pr * z
        if clip_lower is not None or clip_upper is not None:
            theta = jnp.clip(
                theta,
                a_min=clip_lower if clip_lower is not None else -jnp.inf,
                a_max=clip_upper if clip_upper is not None else jnp.inf,
            )
        numpyro.deterministic(name, theta)
        return theta
    ```

        model_name: str,

        Returns a dict keyed by parameter name with (lower, upper) tuple
        values. κ-family bounds depend on ``kappa_parameterization``:

      # parameterization branch - softmax-bias (Collins 2025) vs convex-mixture (Senta 2025)
      if parameterization == "softmax":
          # Add kappa as a softmax additive bias on the last-chosen action logit
          last_action_one_hot = jnp.eye(num_actions)[jnp.maximum(last_action, 0)]
          # Mask out invalid last_action with zeros (no bias on first trial)
          mask = (last_action >= 0).astype(jnp.float32)
          last_action_one_hot = last_action_one_hot * mask
          # Compose hybrid logits: omega * beta*WM + (1-omega) * beta*Q + kappa * I(a, a_{t-1})
          rl_logits = FIXED_BETA * q_vals
          wm_logits = FIXED_BETA * wm_vals
          # Mixed value channel weighted by omega (logit-space mix; Collins 2025 WMH)
          mixed_logits = omega * wm_logits + (1.0 - omega) * rl_logits
          # Add perseveration bias to last-action logit
          biased_logits = mixed_logits + kappa * last_action_one_hot
          # Apply epsilon noise after softmax
          base_probs = jax.nn.softmax(biased_logits)
          noisy_probs = (1.0 - epsilon) * base_probs + epsilon / num_actions
      else:  # parameterization == "convex" - preserved bit-for-bit
          choice_kernel = jnp.eye(num_actions)[jnp.maximum(last_action, 0)]
          hybrid_probs_m3 = (1 - kappa) * noisy_base + kappa * choice_kernel
          noisy_probs = jnp.where(use_m2_path, noisy_base, hybrid_probs_m3)
