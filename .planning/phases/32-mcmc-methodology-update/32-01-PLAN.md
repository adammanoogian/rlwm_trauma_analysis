<objective>
Tighten the post-fit convergence gate to match the Baribault & Collins (2023)
Tier-1 publication standard (R-hat ≤ 1.01, ESS ≥ 400, divergences = 0,
BFMI ≥ 0.2). Extend the per-participant CSV schema with BFMI and per-chain
ESS columns so downstream audit scripts can diagnose label-switching and
single-chain pathologies that the existing all-chain summary hides.

Purpose: The current gate (R-hat < 1.01 AND ESS > 400 AND div == 0) is
already correct for R-hat / ESS / divergences but does NOT check BFMI.
Baribault 2023 explicitly lists BFMI < 0.2 as the diagnostic for an
inefficient Hamiltonian — the gate must include it before we publish.

Output: A hardened convergence gate, additive CSV schema fields, and an
integration test that proves the gate fails on a synthetic R-hat = 2.0
fixture and passes on the M6b real-data fit.
</objective>
